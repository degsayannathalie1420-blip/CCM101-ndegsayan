# Mission 1: Welcome to the Cloud

## Mission Overview

Congratulations!

You have been accepted as a **Junior Cloud Infrastructure Engineer Trainee** at **CloudNova Technologies**, a

company specializing in cloud infrastructure, virtualization, and enterprise cloud solutions.

As part of your onboarding process, you must complete your first mission. Before deploying cloud services or

managing enterprise infrastructures, every cloud engineer must first learn how to work inside a Linux

environment, document their work professionally, and maintain a version-controlled portfolio using GitHub.

Your task is to complete the onboarding mission using the **KillerCoda Playground** and create your personal

**Cloud Computing Portfolio** on GitHub. This portfolio will serve as your professional workspace throughout the

semester and will be updated after every laboratory activity.

Complete each checkpoint carefully. Every completed task represents a real-world responsibility of a cloud

engineer.

## Objectives

Upon successful completion of this mission, you should be able to:

* Access a cloud-based Linux environment using KillerCoda.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Organize files and directories using Linux commands.
* Create and maintain a professional GitHub repository.
* Document technical work using Markdown.
* Demonstrate proper documentation practices used by cloud professionals.

## Activities Performed

For this laboratory activity, I started an Ubuntu 24.04 Linux environment using the KillerCoda Playground. I checked that the terminal was working and created my own Linux user account with Bash, a home directory, and sudo access.

I then logged in using my new account and checked my username, current working directory, and hostname. After that, I investigated the Linux environment by checking the Ubuntu version, kernel version, CPU, memory, and available disk space.

I also created the required folders and Markdown files for the laboratory. The files were organized so that the activity can be documented and uploaded to GitHub as part of my Cloud Computing portfolio.

## Linux Commands Used

| Command       | Purpose                                   |
| ------------- | ----------------------------------------- |
| `pwd`         | Displays the current working directory.   |
| `whoami`      | Displays the current username.            |
| `hostname`    | Displays the hostname of the system.      |
| `useradd`     | Creates a new Linux user.                 |
| `passwd`      | Sets or changes a user's password.        |
| `usermod`     | Modifies an existing user account.        |
| `su`          | Switches to another user account.         |
| `id`          | Displays user and group information.      |
| `lsb_release` | Displays Linux distribution information.  |
| `uname`       | Displays kernel information.              |
| `lscpu`       | Displays CPU information.                 |
| `free`        | Displays memory information.              |
| `df`          | Displays disk space information.          |
| `mkdir`       | Creates directories.                      |
| `cd`          | Changes the current directory.            |
| `nano`        | Creates and edits text or Markdown files. |
| `cat`         | Displays the contents of a file.          |

## Skills Learned

This activity helped me become more familiar with working in a Linux environment through a terminal. I practiced creating a user account, switching between users, navigating directories, and checking system resources.

I also learned how to organize files using folders and Markdown files. Another important part of the activity was learning how these files can be prepared for version control and uploaded to GitHub.

The activity gave me a better understanding of why documentation and organization are important when working with cloud infrastructure.
