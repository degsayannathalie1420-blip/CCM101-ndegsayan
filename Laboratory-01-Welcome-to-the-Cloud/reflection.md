# Reflection

This laboratory activity was my first experience working with a Linux environment through KillerCoda. Before doing the activity, I was more familiar with using a computer through a graphical interface, so using the terminal felt a little different at first.

One of the things I learned was how to create and manage a Linux user. I also practiced basic commands such as `pwd`, `whoami`, and `hostname`. These commands were simple, but they helped me understand how to check where I am working and which account I am using.

I also learned how to check the resources of a Linux system. Looking at the CPU, memory, kernel, and disk space made me realize that system information is important when managing a computer or server. It is useful to know how many resources are available before running applications or services.

Creating the folders and Markdown files also showed me why proper organization matters. Instead of keeping everything in one place, the files were separated according to their purpose. This makes the project easier to understand and maintain.

The GitHub part of the activity is also useful for me because I can use the repository as a record of the activities I complete in this subject. I am still getting used to Git commands, especially committing and pushing files, but practicing them in this activity made the process easier to understand.

Overall, this activity gave me a basic introduction to the kind of environment that cloud engineers work with. I know there are still many Linux and cloud concepts that I need to learn, but this was a good starting point for me.
