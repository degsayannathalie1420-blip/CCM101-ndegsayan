# Mission 3: Become a Multi-Cloud Explorer

## Introduction

This laboratory activity explores three major cloud computing platforms: Amazon Web Services, Microsoft Azure, and Google Cloud Platform. The activity focuses on identifying their services, comparing their capabilities, and determining which platform is appropriate for different types of organizations.

## Linux Server Information

The Linux environment used for this activity has the following specifications:

- Operating System: Ubuntu 24.04.4 LTS
- Kernel Version: 6.8.0-138-generic
- CPU: Intel Xeon E312xx (Sandy Bridge, IBRS update)
- CPU Cores: 1
- Memory: 1.9 GiB
- Available Memory: 1.5 GiB
- Swap: 1.0 GiB
- Storage: 19 GiB
- Available Storage: 13 GiB

## Possible Cloud Migration

The Linux server could be moved to a virtual machine service provided by any of the three major cloud platforms.

### AWS

Amazon EC2 can provide a Linux virtual machine with configurable computing resources.

### Microsoft Azure

Azure Virtual Machines can host Linux systems and provide adjustable computing, storage, and networking resources.

### Google Cloud Platform

Google Compute Engine can be used to create a Linux virtual machine and select resources according to the workload.

## Conclusion

The KillerCoda environment provides a practical example of a Linux server that can be hosted in the cloud. Cloud computing makes it possible to use virtual resources without directly managing the physical server hardware.
