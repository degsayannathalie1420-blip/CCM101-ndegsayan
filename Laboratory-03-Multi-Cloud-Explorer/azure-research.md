# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud platform that provides computing, storage, networking, database, security, and application services. It is widely used for both cloud-based and hybrid environments.

## Global Infrastructure

Azure has a worldwide infrastructure organized into regions and datacenters. Organizations can select locations based on factors such as application performance, availability, and business requirements.

## Cloud Management Console

The Azure Portal provides a graphical interface for managing Azure services. Users can create virtual machines, configure networks, monitor resources, and manage other cloud services from the portal.

## Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provide virtual computing environments for Windows and Linux systems.

### Azure Blob Storage

Azure Blob Storage is designed for storing unstructured data such as documents, images, videos, and backups.

### Azure Virtual Network

Azure Virtual Network allows Azure resources to communicate through configurable virtual networks.

### Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and organizational resources.

## Three Advantages

1. Azure works closely with Microsoft products and technologies.
2. It supports hybrid cloud environments.
3. It provides services for both small projects and large organizations.

## Typical Enterprise Use Cases

Azure can be used for Windows and Linux servers, business applications, databases, identity management, hybrid infrastructure, and enterprise cloud systems.
