## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is a strong choice for organizations that need many different cloud services. It provides options covering infrastructure, storage, databases, networking, security, analytics, and application development.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the most suitable provider for organizations that already depend on Microsoft products. Its services can work closely with technologies such as Windows Server, Microsoft 365, and Active Directory.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for AI and Kubernetes workloads. Its cloud platform provides services for machine learning as well as Google Kubernetes Engine for containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would choose AWS because it provides many services that can be useful for different types of projects. Having several services available on one platform would give me more options when developing and expanding an application.
