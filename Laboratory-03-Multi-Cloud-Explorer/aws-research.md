# Amazon Web Services Research

## Brief Overview

Amazon Web Services is a cloud computing platform that provides infrastructure and managed services for organizations. Its services cover areas such as computing, storage, networking, databases, security, and application development.

## Global Infrastructure

AWS operates a worldwide cloud infrastructure divided into Regions and Availability Zones. This structure allows organizations to deploy applications in locations that can provide suitable availability and performance.

## Cloud Management Console

The AWS Management Console is a browser-based interface where users can create and manage cloud resources. It provides access to different AWS services without requiring users to manage everything through the command line.

## Four Core Services

### Amazon EC2

Amazon EC2 provides virtual servers that can be used to run applications and operating systems.

### Amazon S3

Amazon S3 is an object storage service used for files, backups, application data, and other stored information.

### Amazon VPC

Amazon VPC provides a virtual networking environment where AWS resources can communicate securely.

### AWS IAM

AWS IAM manages identities and permissions and determines which users or services can access AWS resources.

## Three Advantages

1. AWS provides many different services under one cloud platform.
2. Its infrastructure can support applications deployed around the world.
3. Resources can be adjusted based on changing workload requirements.

## Typical Enterprise Use Cases

AWS can support enterprise websites, application servers, databases, backups, storage systems, analytics platforms, and other business applications.
