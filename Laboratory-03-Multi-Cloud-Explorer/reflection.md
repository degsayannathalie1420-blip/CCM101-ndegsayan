# Mission Reflection

This laboratory gave me a clearer idea of how cloud providers can offer similar services while still having different strengths. I learned that AWS, Azure, and Google Cloud all provide important cloud resources, but the best option depends on what an organization is trying to accomplish.

Among the three platforms, Google Cloud interested me the most because of its connection with data processing, artificial intelligence, and Kubernetes. I also found it interesting that cloud platforms allow users to create resources without having to purchase the physical equipment themselves.

AWS, Azure, and Google Cloud have several similarities. They all provide virtual machines, storage, networking, identity management, databases, and other services needed by modern applications. Another similarity is that their resources can be scaled depending on the amount of work being handled. This makes cloud computing useful for organizations whose requirements can change over time.

The requirements of a business are an important part of selecting a cloud provider. For example, an organization that already uses Microsoft products would have a strong reason to consider Azure. A company working with machine learning may benefit from Google Cloud, while an organization looking for a large selection of services may consider AWS.

The consultant role in this activity helped me understand that cloud recommendations should not be based only on which platform is popular. The actual requirements, existing technologies, budget, and expected workload should be considered before selecting a platform.

My GitHub portfolio became more organized after completing this activity. I added research files, comparison tables, recommendations, Linux information, screenshots, and a reflection.
