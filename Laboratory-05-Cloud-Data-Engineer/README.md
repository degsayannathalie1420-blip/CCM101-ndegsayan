
# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory introduced object storage and showed how it can be deployed as a cloud service. I used Docker to run MinIO, accessed the MinIO Console through a forwarded port, created a bucket, and uploaded a sample object.

## Objectives

* Compare block, file, and object storage.
* Deploy an S3-compatible storage service.
* Use Docker to run MinIO.
* Access the MinIO Console through a forwarded port.
* Create and use an object storage bucket.
* Document the completed cloud storage setup.

## Tools Used

* KillerCoda
* Ubuntu
* Docker
* MinIO
* Git
* GitHub
* Web Browser

## Skills Learned

* Running cloud services with Docker
* Using Linux commands
* Understanding object storage
* Managing buckets and objects
* Using port forwarding
* Creating technical documentation with Markdown
* Updating a GitHub cloud computing portfolio
