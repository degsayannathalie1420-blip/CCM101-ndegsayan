## Principle of Least Privilege (PoLP)
The Principle of Least Privilege ensures that every user or service receives only the access necessary for its responsibilities. This limits accidental changes, reduces opportunities for misuse, and helps protect important cloud resources.

## Attack Surface
The attack surface refers to the possible ways an attacker can communicate with or exploit a server. Services listening on unnecessary ports and applications with security weaknesses create more opportunities for attacks.

## Default Deny Policy
A Default Deny firewall configuration refuses incoming connections by default and permits only traffic covered by approved rules. It is safer because administrators can define a small set of necessary connections instead of leaving the server broadly accessible.
