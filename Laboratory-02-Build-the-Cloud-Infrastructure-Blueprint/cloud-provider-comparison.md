# Major Cloud Provider Comparison

## Equivalent Infrastructure Services

| Service Area        | Amazon Web Services | Microsoft Azure                 | Google Cloud     |
| ------------------- | ------------------- | ------------------------------- | ---------------- |
| Virtual Servers     | Amazon EC2          | Azure Virtual Machines          | Compute Engine   |
| Cloud Storage       | Amazon S3           | Azure Blob Storage              | Cloud Storage    |
| Network Environment | Amazon VPC          | Azure Virtual Network           | Google Cloud VPC |
| Access Management   | AWS IAM             | Microsoft Entra ID / Azure RBAC | Cloud IAM        |

## Discussion

### Which provider has the most extensive service ecosystem?

AWS provides a large collection of cloud services for infrastructure, storage, databases, networking, security, analytics, and application development. This wide selection gives organizations many possible services to combine when building cloud solutions.

### Which cloud platform fits organizations that depend on Microsoft tools?

Azure is often a practical choice for organizations that already use Microsoft technologies. Its services can work closely with Microsoft systems and identity tools, which can simplify the transition of existing workloads into the cloud.

### Which provider has a strong focus on AI, machine learning, and containers?

Google Cloud is known for its services related to artificial intelligence and machine learning. It also provides Google Kubernetes Engine, which helps organizations deploy and manage container-based applications.

### What is the major similarity between the three providers?

All three providers offer the core services required to build cloud infrastructure. Each platform includes computing, storage, networking, and identity management services. The main differences are usually found in the service names, management tools, and additional features.

## Conclusion

Learning cloud infrastructure is not limited to memorizing product names. Understanding the purpose of compute, storage, networking, and identity services makes it easier to recognize equivalent services across different cloud platforms.
