# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Introduction

This laboratory focused on examining the resources that support a cloud computing environment. A Linux server was investigated through KillerCoda to collect information about the operating system, processing resources, memory, network configuration, and storage.

The activity also explored the basic services offered by major cloud providers and demonstrated how cloud components can be organized in a simple infrastructure architecture.

## Objectives

* Investigate the configuration of a Linux server.
* Identify important compute, storage, and network resources.
* Understand the purpose of major cloud infrastructure components.
* Compare equivalent services across cloud providers.
* Create a basic cloud infrastructure design.
* Organize technical documentation using Git and GitHub.

## Laboratory Environment

The activity was completed in a KillerCoda Ubuntu Linux environment. The server provided virtual processing, memory, disk storage, and network resources for the investigation.

## Tools Used

* KillerCoda
* Ubuntu Linux
* Linux Terminal
* Git
* GitHub
* Markdown

## Learning Outcome

After completing this activity, I gained additional experience in investigating Linux infrastructure and connecting those technical resources to basic cloud computing concepts. I also practiced documenting technical work and maintaining an organized GitHub repository.
