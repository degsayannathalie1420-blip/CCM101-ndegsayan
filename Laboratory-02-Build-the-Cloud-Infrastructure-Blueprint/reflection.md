# Laboratory Reflection

## 1. Which cloud infrastructure component do you consider most important?

I believe that compute is one of the most important parts of cloud infrastructure because applications need processing power to perform their tasks. CPU and memory make it possible for programs to run, process user requests, and handle workloads.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable environment for servers and virtual machines. It gives administrators tools for managing users, processes, files, storage, and networking. During this activity, the Linux command line was useful for checking the actual resources available in the virtual environment.

## 3. Why is it important to document infrastructure before deployment?

Documentation provides a reference for the planned infrastructure. It helps explain what resources are available, how systems are connected, and what configuration has been selected. Good documentation can also make future maintenance and troubleshooting easier.

## 4. What did you learn during this laboratory?

I learned how to gather and organize technical information from a Linux environment. I became more familiar with identifying operating system details, processor resources, memory, network interfaces, and storage devices. The activity also helped me understand how these resources relate to cloud computing.

## 5. How did this laboratory improve your GitHub portfolio?

My portfolio became more complete because the laboratory work is organized into separate reports and supporting evidence. The repository now shows infrastructure information, cloud concepts, provider comparisons, screenshots, and a system architecture design. This provides a clearer record of the skills practiced during the activity.
